# 种业联合研发转化后台

定义从**育种材料**到**上市品种与推广反馈**的贯通关系，让科研单位能判断企业需求是否获得证据支持，企业能从上市品种一直追到材料来源、试验条件、许可权利与实际种植表现。

## 领域资料

- `contracts/context.schema.json` / `fixtures/context.json`：早期共享资料格式（参与者、事实、约束）。
- `contracts/backend.schema.json`：联合研发转化后台结构合约。
- `fixtures/backend.json`：可公开使用的**虚构**样例，不含真实个人信息、账号、密钥或连接凭据。

代码读取器先过结构合约，再做引用完整性与业务规则检查：

- `src/schema_lite.py`：零依赖的 JSON Schema 子集校验器（环境未安装 `jsonschema`）。
- `src/backend.py`：语义校验、按参与方脱敏、谱系与追溯查询。

## 贯通的业务链路

```
种质材料 ──移交(用途/数量/繁殖代次)──> 团队谱系分支
   └─ 亲本组合(crosses)
        └─ 企业材料阶段需求 → 试验指标 → 多点多年方案/点年/观测(含失败与负面结果)
             └─ 品种审定(版本化、带适宜区域) + 区域适配/栽培技术变更(只作用于明确范围)
                  └─ 知识产权比例(版本化、各方同时确认) ─ 许可(商业条款按参与方隔离)
                       └─ 推广面积与种植表现回传 ─ 品种撤回(证据链+时间+终止许可)
```

样例围绕两个虚构品种展开：

- **金甜玉1号（V-ZN2026001）**：企业在育种材料阶段提出的口感、加工、机械化要求转化为皮渣率、出籽率、机收损失率等可考核指标；宜昌点出籽率未达标的**负面结果保留**，该区域不进入审定适宜区；黄淮海机收配套技术与区域适配变更只作用于黄淮海；知识产权比例由 60/10/30 调整为 55/10/35 并由各方重新确认。
- **雪甜糯9号（V-ZN2025009）**：多点试验与大区监测复现高湿年型茎腐病风险，凭负面结果证据链主动**撤回**，关联许可终止，全流程留有时间与多方确认依据。

## 关键规则（由校验器强制）

- **材料移交**必须写明用途、数量、当前代次与允许繁殖代次，并由相关合作方确认。
- **同一资源多团队使用**时，各团队在同一谱系根下保持独立、可追踪的分支，禁止跨团队串联，分支须能对应到移交单。
- **企业需求**必须至少绑定一个试验指标；`demand_evidence` 汇总多点多年点次，给出 `supported / not_supported / pending_evidence` 判定，负面点次计入。
- **失败与负面结果**单独登记且原始观测保留；被负面登记引用的观测必须带 `negative` 标记。
- **未公开性状、受限观测、许可商业条款**带 `visible_to`（`"*"` 为全公开），`view_for_party` 按参与方隔离；许可的存在与授权范围仍可见，仅隐去金额费率。
- **审定版本、区域适配、栽培技术**均带 `scope`，变更只作用于明确区域/点；`effective_packages`、`licenses_in_force` 按区域与日期解析生效项。
- **知识产权比例**合计须为 100，调整生成新版本且全部持份方同时确认。
- **多方确认、面积回传、撤回**等动作均带时间字段；`timeline(variety_id)` 沿材料来源祖先链给出该品种的时间依据。

## 追溯查询

```python
import json
from src import backend as B

d = B.load_backend("fixtures/backend.json")

B.view_for_party(d, "ENT-02")                 # 某参与方视角（脱敏副本）
B.lineage_branches(d, "GP-007")               # 同一材料在各团队的谱系分支
B.demand_evidence(d, "D-02")                  # 企业需求是否有证据支持
B.trace_variety(d, "V-ZN2026001")             # 上市品种→材料/试验/权利/表现
B.effective_packages(d, "V-ZN2026001", "黄淮海夏播区", "2026-07-01")
B.licenses_in_force(d, "V-ZN2026001", "黄淮海夏播区", "2026-08-01")
B.timeline(d, "V-ZN2026001")                  # 该品种全部带时间的关键动作
```
