# 种业联合研发转化

定义种质材料、联合试验、品种权利和推广反馈的关系。

## 领域资料

`contracts/context.schema.json` 定义共享资料格式，`fixtures/context.json` 提供可公开使用的虚构样例。领域资料按版本保存参与者、事实与约束，代码中的读取器负责检查必要字段与集合间引用。

当前资料反映以下业务事实：

- 部分品种在试种后面临推广最后一公里困难
- 企业将从育种材料阶段参与研发
- 品种推广依赖区域适配和配套栽培技术
- 失败与负面结果和正面结果同等保留
- 同一资源由多个团队使用时各自保持可追踪谱系

## 联合研发转化后台

样例贯通以下链条，每个环节都可向前向后追踪：

1. **参与方与品类**：科研单位、企业、试验点和特色品类（鲜食糯玉米、加工番茄）。
2. **种质材料**：公开性状与未公开性状分列；未公开性状只对保存方或经移交实际接收的团队可见。
3. **材料移交**：每次移交记录用途、数量、繁殖代次和时间，并产生接收方自己的谱系分支。
4. **谱系分支**：同一资源由多个团队使用时各自维护繁殖代次记录，可追踪到来源移交。
5. **亲本组合**：父母本引用谱系分支或种质材料，组合时间与组配单位留痕。
6. **企业需求**：口感、加工、机械化要求转成试验指标库中的可检验指标，并标记证据支持状态（testing / supported / partial / unsupported）。
7. **试验方案与数据**：多点多年方案关联组合与指标；观测记录含 positive / negative / failed 三类结果，失败与负面结果不删除。
8. **品种审定**：审定版本与适用区域构成明确范围；撤回品种保留撤回时间。
9. **配套技术**：栽培技术版本只作用于审定范围内的明确区域。
10. **许可**：商业条款仅许可双方可见；知识产权比例之和为 1，调整须双方同时确认并留时间。
11. **推广反馈**：企业回传推广面积与实际种植表现。
12. **事件**：合作方同时确认、知识产权比例调整、推广面积回传、品种撤回均带时间依据，并与对应记录交叉一致。

`src/context.py` 的 `validate_integrity` 强制执行上述引用、隔离、范围与时间约束；`trace_license` 支持从许可一路追到品种审定、亲本组合、种质来源、试验条件与实际种植表现。
